# Этот репозиторий содержит результат работы команды №2 по первой задаче хакатона SF_DSMED
_21 июля - 5 августа 2025 г._
---

В процессе работы из предложенных данных был сформирован датасет, в котором представленные результаты лабораторных тестов были скомпонованы в лабораторные исследования. Компоновка проводилась на основе двух принципов:
1. Лабораторные тесты в представленном наборе расположены сверху вниз в порядке выполнения (самые старые в первых строках, самых свежие в последних).
2. В одном лабораторном исследовании тесты не повторяются.
Это позволило подготовить обучающий датасет таким образом, чтобы модели при обучении не теряли существующую связь между показателями.

Применено несколько способов разметки полученного датасета:
- по заранее прописанным правилам, которые были сформированы экспертами
- с помощью моделей кластеризации
- с помощью LLM модели

Результаты разметки проверялись вручную экспертами с целью определения лучшей.

На базе датасета с лучшей разметкой обучены несколько вариантов моделей из которых был выбран лучший на основании метрик классификации и степени переобучения.

Исследовательская работа по формированию датасета, разметке, анализу данных и обучению моделей представлена в файлах:
- ```1 Работа с данными - Хакатон_Команда_№2.ipynb```
- ```2 Обучение моделей - Хакатон Команда №2.ipynb```

Было разработано web-приложение на базе ```Flask+javascript+css```. Основной код приложения в файле ```app.py```, в ```data.py``` хранятся статичные словари и функции, и данные для отладки. ```predict.py``` - скрипт старта инференса и предсказания по данным формы на основании дампа лучшей модели.

Данное web-приложение развернуто в виде связки ```Flask+uWSGI``` на виртуальном хостинге по адресу [https://hackathon.lex-test.ru/](https://hackathon.lex-test.ru/)
