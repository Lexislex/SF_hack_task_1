# Это рабочий репозиторий команды по первой задаче хакатона SF_DSMED июль 2025

В репозитории 3 ветки:
- `main` - основная здесь будет находиться датасет, финальный Jupyter Notebook, финальные инференсы моделей
- `research` - ветка где будет вестись основная работа по EDA и обучению моделей. каждый работает в своем ноуте, потом лучшее сводим в финальный и его будем коммитить в ветку main
- `webapp` - ветка где будет находить ся код web приложения, скрипт исполнения инференса, инфернесы моделей.
